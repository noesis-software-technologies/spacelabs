Règle unique : sur une annonce à 30 offres, le client lit trois lignes. Preuve de lecture du brief, preuve de compétence, une question. Pas de présentation d'entreprise en tête. On écrit au nom de l'équipe projet NOESIS SOFTWARE TECHNOLOGIES.

Interdits : « nous sommes une agence spécialisée… », listes de technos, liens portfolio générique, toute mention d'outils d'assistance internes.

Modèle 1 — Offre annonce ouverte, score ≥ 70

Bonjour,

Sur votre besoin de [reformulation en une ligne, avec le détail technique qui prouve qu'on a lu], le point qui décide du budget est [contrainte réelle : volumétrie, intégration existante, reprise de données…].

Nous avons livré ce type de plateforme en Python/Django, dont [référence comparable en une ligne]. Sur votre périmètre, je situe la mission entre [fourchette] selon la réponse à un point : [la question qui change le chiffrage].

Je peux vous envoyer un découpage en lots d'ici demain si cela vous aide à comparer.

[Prénom Nom] — NOESIS SOFTWARE TECHNOLOGIES

Modèle 2 — Offre annonce ouverte, score 45 à 69

Bonjour,

Votre annonce porte sur [reformulation en une ligne]. Deux éléments manquent pour chiffrer sérieusement : [point 1] et [point 2].

Si vous me les précisez, je vous renvoie un devis ferme dans la journée. Nous développons ce type d'application en Python/Django, avec reprise de l'existant quand il y en a un.

[Prénom Nom] — NOESIS SOFTWARE TECHNOLOGIES

Modèle 3 — Relance à J+3

Bonjour,

Je reviens vers vous sur [titre du projet]. Avez-vous avancé sur votre sélection ?

Si le sujet est en pause, dites-le-moi simplement, je n'insisterai pas. Si vous hésitez sur le périmètre, je peux vous faire un découpage en lots pour démarrer sur une première tranche.

[Prénom Nom] — NOESIS SOFTWARE TECHNOLOGIES

Modèle 4 — Opportunité future (annonce « En cours »)

Bonjour,

Vous aviez publié [titre du projet] il y a [durée]. Nous intervenons régulièrement en reprise sur ce type d'applicatif, quand un développement s'arrête en cours de route ou qu'il faut le faire évoluer après la livraison.

Si le projet est en production et que vous cherchez une équipe pour la suite, je peux vous faire un point technique gratuit sur l'existant.

[Prénom Nom] — NOESIS SOFTWARE TECHNOLOGIES

Modèle 5 — « Demande de devis » sans budget

Bonjour,

Pour vous donner un chiffre utile plutôt qu'une fourchette large, j'ai besoin de deux réponses : [question volumétrie/utilisateurs] et [question sur l'existant à reprendre].

Avec ça je vous envoie un devis découpé en lots, ce qui vous permet de démarrer sur une première tranche et d'arbitrer la suite.

[Prénom Nom] — NOESIS SOFTWARE TECHNOLOGIES
