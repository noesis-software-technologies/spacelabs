Un poste de pilotage, pas un chatbot

Un pane par agent, un mur d'agents par écran. La sortie des agents est le contenu ; l'interface s'efface.

Panes terminal temps réel

Un vrai PTY dans le navigateur (WebSocket + Channels), buffer rejoué à la reconnexion.

Reprise de session

Rafraîchir, planter, redémarrer : la grille se restaure et l'historique revient.

Multi-workspaces

Plusieurs projets côte à côte, plafond configurable par workspace et par compte.

Vue spectateur

Un flux anonyme read-only, panes privés expurgés côté serveur — pensé pour le live.

Aucune clé API

SpaceLabs spawne le binaire claude déjà authentifié sur votre machine. Vos abonnements, vos crédits, vos credentials restent chez vous.
